chext

DOM 추출·편집과 AI 채팅 내보내기 북마클릿 · GitHub 저장소

설치 방법

  1. 필요한 북마클릿의 복사 버튼을 누릅니다.
  2. 브라우저에서 새 북마크를 만들고, URL/주소 필드에 복사한 코드를 붙여넣습니다.
  3. 대상 페이지에서 북마클릿을 실행합니다.

모바일 브라우저는 북마클릿 URL 길이에 제한이 있을 수 있습니다. Native Single이 잘리지 않으면 그대로 사용하고, 잘리면 Split을 선택하세요. 클립보드 복사가 제한되면 파일 링크에서 원문을 확인할 수 있습니다.
